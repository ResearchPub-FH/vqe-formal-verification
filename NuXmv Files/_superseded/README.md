(generated by `2-stage verification (closed-loop)/closed_loop/logical.py`, which

| --- | --- |

| `VQE_NuXmv_Refinement/` | Refined-ABORT model, 41 properties, scaling runs, counterexamples ce1-ce3 |

| `VQE_Phase_Reachability/` | Phase reachability for baseline, refined and canonical models |

`2-stage verification (closed-loop)/audit/legacy_controller.py` for the audit
of the approved experiment.
