             X. D ISCUSSION AND L IMITATIONS
• Hardware noise modeling. Current abstraction assumes
  a declared shot-noise model; richer hardware-specific
  noise (crosstalk, leakage, drift) is future work.
• Concurrent and distributed VQE. The shared model
  is sequential; extending to multi-backend or batched
  execution is open.
• Floating-point semantics in the classical optimizer. Not
  currently modeled; bounded by numeric-layer invariants
  but not formally verified.
• Adversarial backends. The architecture assumes a co-
  operative cloud backend; security verification is out of
  scope.
• Generalization to other hybrid algorithms. QAOA,
  VQD, and quantum machine learning loops fit the same
  skeleton; sketch the migration path.
